# Kingroon-KP3S-Marlin-Firmware-Fork
A Marlin firmware for Kingroon KP3S

Note: This branch is W.I.P.

Based on build 2.1.3-b2 (Marlin 2.1.3 beta 2) of 2025-01-16

It's for Kingroon mainboard 1.3 with GD32F303 chip.

(OctoPrint is recommended for this Marlin Firmware)

## Main features:

Input shaping,
Linear advance,
Power loss recovery (on by default),
Runout sensor support (on by default),
French, English and more languages,
Portrait screen,
Long file name scrolling,
Double touch select,
290°C and hotend with 110°C bed,
PLA, PETG, TPU and ABS Preheat Settings.

### With BL Touch:
16 pints automated bed leveling.

### With Serial Port:
MeatPack,
250000 Baud rate (by default) with M575,
Serial DMA and Advanced OK.
